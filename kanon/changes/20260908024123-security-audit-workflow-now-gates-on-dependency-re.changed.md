Security Audit workflow now gates on dependency REACHABILITY instead of a flat package-name allowlist. scripts/audit-allowlist.ts computes which packages are reachable from the shipped surface (workspace root deps minus the dev/CI-only roots promptfoo and @codecov) from bun.lock; a high/critical advisory fails the build only when its package is shipped-reachable. The entire promptfoo/@codecov subtree is accepted automatically, so escalated transitive advisories (e.g. fast-xml-parser) no longer require per-package allowlist edits. js-yaml remains a documented package-level exception. Adds unit tests for the reachability logic.
