Kiro progressive-steering rubric: grade the harness directory itself, not its parent. Pointing --build one level above the kiro/ folder made every artifact name resolve to "kiro", zeroing FMP and MD and producing a false RED in the eval-kiro-progressive-steering CI gate. The runner now auto-descends into a kiro/ (or dist/kiro/) wrapper, pairs each build with its own scenario workload, adds a --workload override, and the workflow points --build at expected-build/kiro. Adds a CLI regression test asserting both the parent and harness build paths grade GREEN with exit 0.
