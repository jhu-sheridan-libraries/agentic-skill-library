Release workflow no longer fails on its final step. The 'Commit changelog update' step pushed the compiled CHANGELOG.md directly to the protected main branch, which is rejected by repository rules (PR-only, verified signatures, CodeQL) — so every release red on its last step even after the GitHub Release published. It now opens a changelog-sync PR via peter-evans/create-pull-request instead, and is continue-on-error so a sync hiccup never reds a completed release. Adds pull-requests: write permission.
