Migrate js-yaml from 4.x to 5.x. js-yaml 5.x ships its own types (so @types/js-yaml is removed, not bumped) and is ESM named-exports only with no default export: all 'import yaml from js-yaml' become 'import * as yaml from js-yaml' and dynamic-import 'yaml.default.dump' calls become 'yaml.dump'. Dump options renamed/removed: quotingType -> quoteStyle ('single'|'double'), noCompatMode dropped (5.x safely quotes YAML-1.1-ambiguous scalars by default; values round-trip identically). Empty/whitespace aux YAML is now guarded before yaml.load, which throws on empty input in 5.x where 4.x returned undefined, preserving the empty-array contract. Full suite green (3656 tests).
